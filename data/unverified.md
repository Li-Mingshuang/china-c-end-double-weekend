## 五、搜索噪声与易误引（务必排除）

检索「某公司是否双休」时，以下命中项**不是**该公司的证据：

| 命中项 | 实际指向 |
|---|---|
| 「长城实行全面双休」出现在汽车之家论坛 | 那是**长城汽车**的消息，与汽车之家公司无关 |
| 「郫县豆瓣股份有限公司」的单双休问答 | 那是**食品企业**，与豆瓣网无关 |
| 「上五休二」客服岗出现在 51job | 那是**平台上的第三方岗位**，非前程无忧自身雇员 |
| 58 同城上的招聘信息 | 那是**平台上的第三方岗位**，非 58 自身雇员 |
| 「北京西山居酒店管理有限公司」 | 那是**酒店业**，与金山旗下游戏工作室西山居无关 |
| 「找工易 XX 有双休吗？」类页面 | **提问页本身不含任何答案内容**，不构成证据 |
| 泡泡玛特「江西代工厂剥削劳工」报道 | 属**供应链用工**，与总部员工工时无关 |
| 某公司《供应商行为准则》（如 OPPO） | 约束的是**供应链**，不是本公司员工的作息 |

## 六、调研方法上的硬性局限（必读）

本次调研**只能使用搜索工具**（沙箱禁止直接抓取网页正文，`curl` / `Invoke-WebRequest` 均被网络层拒绝），因此证据来自**搜索结果的标题、摘要与 URL**，无法逐页核对正文。这带来两个后果：

1. **「未找到公开来源」很可能是检索可见性不足**，而不是该公司真的没有双休证据。
2. **证据分级偏保守**：只有标题本身写明「双休 / 取消大小周 / 单休」的报道或招聘页才敢给 A；仅能证明「公司在招人」的一律给 C。

如果你能联网读正文，欢迎按 [CONTRIBUTING.md](../CONTRIBUTING.md) 的要求把本文件里的条目升级、纠错，或补上反例证据。
