# 中国 C 端双休企业清单

> 面向个人消费者的中国企业里，**哪些是双休的**。
>
> 主清单门槛：① 直接面向 C 端消费者；② **全公司范围明确双休**（不是个别部门、个别岗位）。
>
> 数据截止：**2026-09**。每条记录单独标注时间点，政策会变，**请以劳动合同为准**。

---

## 为什么做这个清单

「双休」在国内互联网与消费行业并不是默认项。相当多的公司实行大小周、单休或排班制，而这些信息散落在公司公告、招聘 JD、媒体报道和员工讨论里，**没有一份统一的、每条都附证据链接的公开清单**。

这个仓库要做的是：把「谁双休」变成一份**可查证、可纠错、带时间戳**的表格。

它不生产结论，它只汇编公开证据。**欢迎纠错，纠错优先处理。**

---

## 五、最容易误读的三种口径

把下面三类新闻当成「双休」的证据，是这个话题里最常见的错误：

| 说法 | 实际约束的是什么 | 为什么不能当双休证据 |
|---|---|---|
| 「强制下班」「到点关灯」「9 点必须走人」（2025 年**大疆、美的**、名创优品等） | **每天的下班时间** | 约束的是单日工时，不是每周休息天数。同一家公司完全可以「到点下班 + 周六照常上班」 |
| 「每周居家办公 2 天」「3+2 混合办公」（如**携程**） | **办公地点** | 在家也是上班。混合办公与休息天数无关 |
| 「周末不打卡」「周末线上待命」 | **考勤形式** | 不打卡不等于不用干活；待命更不是休息 |
| 「四天半工作制」（如**乐视**） | 属于**另一类制度** | 比双休更好，但要单独标注，不要与「双休」混为一谈 |
| 「少开会、禁用 PPT、汇报不超 3 页」（2025 年**名创优品**） | **内部管理效率** | 针对形式主义，不涉及休息天数 |

另外请注意两点：

1. **「未出现在 2021 年取消大小周名单里」≠「曾经是大小周」，也 ≠「现在是双休」。** 百度、腾讯、网易、B 站本来就不是公开的大小周公司，不能用名单反推。
2. **「海尔强制双休」是被官方否认的传言。** 2025-03 网传海尔「强制员工双休」，海尔当日回应「没有发过相关通知」。

## 六、排班制：这些岗位既不是双休，也不是单休

以下岗位通常是**轮班 + 月休天数制**，把整家企业标成「单休」或「双休」都不准确。

- **BPO / 外包**：T3 出行、曹操出行、去哪儿网的部分客服岗由外包公司代招，作息按外包方执行。
- **制造业「名义双休、实际单休」** 也很常见，牛客上有机械制造业从业者专门提到这一点（[帖子](https://www.nowcoder.com/feed/main/detail/98f8d6efd990423ca33bf34fa7999550)）。

## 证据分级

| 等级 | 含义 | 典型来源 |
|---|---|---|
| **A** | 官方渠道明确 | 公司公告 / 官方通知、官方招聘 JD 写明「双休」、政府行政许可批复、ESG / 社会责任报告 |
| **B** | 权威或多元二手 | 主流媒体报道、多个互相独立的员工公开反馈一致 |
| **C** | 弱证据 | 单一匿名爆料、口头转述、「听说」、渠道商 / 外包方发布的 JD |

主清单原则上只收 **A** 级；B 级会保留在表中，但明确标注为 B。

## 调研方法上的局限（必读）

本次调研**只能使用搜索工具**（沙箱禁止直接抓取网页正文），证据来自**搜索结果的标题、摘要与 URL**，**未逐页核对正文**。因此：

1. **「未找到公开来源」很可能只是检索可见性不足**，不代表该公司不是双休。
2. **证据分级偏保守**：只有标题本身写明「双休 / 取消大小周 / 单休」的报道或 JD 才敢给 A。
3. 本清单**不发布证据不足的负面结论**，只有「不明」。想说明某公司不是双休，必须给出**同等强度的反例证据**。
4. **制度上的双休 ≠ 实际不加班**：媒体在报道小红书取消大小周时也提示「加班、竞业泛化仍需调整与博弈」，存在**形式上有双休、实际隐形加班**的风险。

## 重要提醒

1. **同公司不同岗位可能完全不同。** 总部研发职能岗双休，不代表门店店员、客服、骑手、产线工人、内容审核岗双休。比亚迪（研发双休 / 普工单休）、B 站（研发相对好 / 审核轮班）就是典型例子。
2. **作息政策随时会变。** 每条记录都带时间点，请自行判断时效。本清单信息主要截至 2026-09。
3. **本清单不是法律意见，也不构成任何录用承诺。** 入职前请以**书面 offer 和劳动合同**为准，并确认劳动合同主体是谁。
4. **欢迎纠错，纠错优先处理。** 如果你发现某条与事实不符，请带上反例证据提 PR / Issue。
